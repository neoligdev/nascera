IA própria dos clientes

Liberado, cada cliente pode conectar a própria chave da Anthropic (API ou assinatura via claude setup-token). Os builds dele passam a rodar por conta dele — o token não sai do seu bolso e os turnos não debitam créditos. Vale para sessões novas.

Custo base = preço da Anthropic por milhão de tokens. Cobrado = base + markup — é o que desconta do orçamento do plano. O ID casa por substring com o modelo real do turno e o mais específico vence ("opus-5" ganha de "opus"); modelo fora da lista usa o custo informado pelo SDK com o markup padrão.

O consumo liberado É o preço convertido em US$ — o cliente recebe exatamente o que pagou, medido no SEU preço de venda (custo Anthropic × markup), igual a Anthropic mede o uso de vocês pelo preço de tabela dela. Consumir US$ 218 "de uso" custa US$ 109 de verdade com markup +100% — a diferença é sua margem: nunca fica negativo, no mínimo repassa o custo. Bônus é subsídio deliberado (free/trial).
