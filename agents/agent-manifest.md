# Agentes Disponiveis

Ative agentes com @nome no chat ou pelo seletor na interface.

| Agente | Papel | Quando Usar |
|--------|-------|-------------|
| @dev | Desenvolvedor Full-stack | Escrever codigo, implementar features, corrigir bugs, refatorar |
| @architect | Arquiteto de Solucoes | Estrutura de projeto, tech stack, design de APIs, decisoes tecnicas |
| @qa | Quality Assurance | Revisao de codigo, testes, acessibilidade, performance |
| @pm | Product Manager | Requisitos, escopo, priorizacao, PRD, estrategia de produto |
| @ux | UX Designer | Layout, design system, fluxos de usuario, cores, tipografia |
| @sm | Scrum Master | Quebrar em tarefas, criar stories, planejar sprints, organizar backlog |

**Agente padrao:** @dev — para implementacao imediata quando nenhum agente e especificado.
